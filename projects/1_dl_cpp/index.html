Describe the motivation behind implementing a deep learning framework from scratch in C++ and the goal of understanding the underlying computational mechanisms rather than relying on existing frameworks.

Motivation

Modern deep learning frameworks such as PyTorch provide highly optimized abstractions for tensors, automatic differentiation, neural networks, and optimization.

This project aims to understand and implement these fundamental components from first principles using standard C++.

Tensor Engine

The project includes a custom tensor abstraction supporting:

  • Scalar tensors
  • One-dimensional tensors
  • Two-dimensional tensors
  • Shape and stride information
  • Tensor indexing
  • Broadcasting
  • Matrix multiplication
  • Gradient storage
