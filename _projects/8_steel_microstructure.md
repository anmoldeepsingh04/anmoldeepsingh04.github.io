## **Abstract**

This project was developed as part of my work as a Student Researcher at the Technical University of Munich, focusing on the application of machine learning and scientific computing techniques to materials engineering and steel microstructure analysis.

The project involved developing a Python-based application to process and analyze microstructural data, providing an interactive interface for exploring computational results and applying machine-learning-based analysis. The work combines scientific data processing, machine learning, and software engineering to create a reproducible workflow for materials-science research.

<ul>
    <li>Developed a Python-based application for interactive analysis of steel microstructure data.</li>
    <li>Implemented machine-learning workflows for processing and analyzing microstructural information.</li>
    <li>Built reproducible data-processing and model-evaluation pipelines for scientific datasets.</li>
    <li>Developed an interactive Streamlit interface for visualization and exploration of computational results.</li>
    <li>Structured the application for reproducible deployment and independent execution of the analysis workflow.</li>
    <li>Integrated scientific computing and machine-learning methods to support materials-engineering research.</li>
</ul>
